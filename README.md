# IE3100 – Virtualization and Cloud Computing Technologies

## MeridianCare Health Network – Cloud Migration Strategy

### Project Overview

This repository contains our group academic assignment for the IE3100 – Virtualization and Cloud Computing Technologies module at the Sri Lanka Institute of Information Technology (SLIIT).

The project focuses on developing a cloud migration strategy for MeridianCare Health Network, a healthcare provider operating 12 clinics and 2 diagnostic laboratories.

Our team acts as external cloud consultants to analyze the existing IT infrastructure, propose a suitable cloud architecture, and prepare a business case for digital transformation.

### Project Objectives

- Propose a scalable and reliable cloud infrastructure.
- Improve system availability and performance.
- Design a disaster recovery strategy.
- Protect sensitive healthcare information.
- Evaluate cloud service delivery models.
- Estimate and compare three-year infrastructure costs.
- Develop a cloud migration risk management strategy.
